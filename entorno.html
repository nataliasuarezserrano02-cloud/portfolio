Mi entorno de trabajo

Qué ocurre cuando escribo una URL

Cuando escribo una URL en el navegador, este solicita la página al servidor. El servidor responde enviando los archivos necesarios y el navegador los interpreta para mostrar la página en pantalla.

Herramientas que utilizo

  • Visual Studio Code: para escribir y editar el código.
  • Live Server: para visualizar los cambios en el navegador.
  • Git: para guardar el historial de cambios.
  • GitHub: para almacenar el repositorio en Internet.
